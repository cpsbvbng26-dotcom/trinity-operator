n = 3,  Q は 巡回置換,  a = [0.5 0.7 0.3]
  ρ(A)  = 0.471769   ← 収束するかどうかはここで決まる
  ‖A‖₂  = 0.700000   ← 論文が縮小定数として挙げているもの
  正規行列: いいえ
  収束: する / 単調減衰: する
  過渡的増幅 maxₖ‖Aᵏ‖₂ = 1.000
  不動点 = (0.754190, 0.527933, 0.508380)

2. 論文の条件を満たさないのに収束する例
n = 2,  Q は 任意の行列,  a = [0.5 0.5]
  ρ(A)  = 0.500000   ← 収束するかどうかはここで決まる
  ‖A‖₂  = 20.012492   ← 論文が縮小定数として挙げているもの
  正規行列: いいえ
  収束: する / 単調減衰: しない
  過渡的増幅 maxₖ‖Aᵏ‖₂ = 20.012   ← 誤差はいったん増えてから減る
