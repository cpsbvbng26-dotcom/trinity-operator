# 一分で試す

```
pip install numpy
python3 examples/one_minute.py
```

リポジトリの根から走らせます。
渡すものは三つです。混合率 `a`、基準点 `p`、影響行列 `Q` です。
`Q` を省くと、三篇と同じ巡回置換になります。

返るものは、スペクトル半径 `ρ`、作用素ノルム `‖A‖₂`、収束するかどうか、不動点、誤差の山です。

出力は [`one_minute.txt`](one_minute.txt) と一字一句同じになります。
`python3 verification/check_docs.py` が、走らせて突き合わせています。

一つめは Series II の設定です。
`ρ = 0.471769` と `‖A‖₂ = 0.700000` が、すでに離れています。

二つめは、論文の条件を満たさないのに収束する例です。
`‖A‖₂` は 1 を大きく超えますが、`ρ = 0.5` なので収束します。
誤差は第 2 段で山になり、そこから減ります。
