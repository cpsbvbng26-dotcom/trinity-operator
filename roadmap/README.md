# 展望 —— この作用素で、コードだけでどこまで言い切れるか

Trinity-Infinity の三篇が扱う作用素 `x ← DQx + (I−D)p` について、**仮定を一つずつ
外していったときに何が残り、何が落ちるか**を、段ごとに実行できる形で並べたものです。

肩書きの段階ではありません。**「コードで言い切れる／推定までしか言えない／
原理的に言えない」の三つで区切っています。**

各段は単独で走ります。

```
python3 roadmap/stage1_optimal_norm.py    # 最善の重み付きノルム
python3 roadmap/stage2_switching.py       # 切り替え系と同時スペクトル半径
python3 roadmap/stage3_stochastic.py      # 確率的な切り替え。二つの「収束」
python3 roadmap/stage4_nonlinear.py       # 非線形な統合。唯一性が落ちる
python3 roadmap/stage5_infinite.py        # 無限次元。ρ が極限へ渡らない

python3 verification/check_roadmap.py     # 63 項目
```

NumPy のみ。乱数種は固定。**この文書に書いた数値は、すべて上のコードが出したものです。**

## いまいる場所（段 0）

| | |
| --- | --- |
| 三篇が言っていること | `‖DQ‖₂ < 1` なので縮小写像、よって Banach、よって唯一の不動点へ幾何収束 |
| 訂正 | 収束の必要十分条件は `ρ(DQ) < 1`。`‖DQ‖₂ < 1` は十分条件にすぎない |
| 補い | `ρ < 1 ≤ ‖A‖₂` で壊れる Banach の議論を、リアプノフ方程式から重み付きノルムを作って組み直した（`certificate.py`） |

ここまでは `check.py`（22 項目）と `verification/check_certificate.py`（51 項目）で
押さえてあります。**新しい数学は一つもありません。**

## 段 1 —— 作った距離は最善ではない

**問い。** `certificate.py` は `P − BᵀPB = I` を解く。右辺の `I` は決め打ちである。
最善はどこか。

**コードが決めること。** 右辺 `W` を動かしても縮小定数 `κ` は動かない。動くのは
ユークリッド距離に戻すときの係数だけ。反例（`ρ = 0.5`、`‖A‖₂ = 20.01`）では:

| κ | 決め打ち `W = I` | 最善 | 差 |
| --- | --- | --- | --- |
| 0.55 | 382.69 | 209.52 | 1.83 倍 |
| 0.75 | 69.35 | 48.00 | 1.44 倍 |
| 0.99 | 34.06 | 27.12 | 1.26 倍 |

**探索が出した最善は、相似変換から出る閉じた式と最大 3.8×10⁻⁶ の相対差で一致します。**
`A = [[a, b], [0, a]]` について係数の最小値は `|b|κ/(κ² − a²)`。片方だけでは
どちらも信用できないので、両方から出しています。

副産物として一つ潰れた仮説があります。**対角の `W` に限ると、何も改善しません。**
最善の `P` は対角なのに、対角な `P` は対角な `W` からは出てこないためです。

- **独自性: 低。** 重み付きノルムの最適化が半正定値計画になることは教科書にある（Boyd 他 1994）。新しいのは「この反例で決め打ちが 1.44 倍損をしている」という測定値だけ。
- **合法性: 問題なし。** 実装は自作、文献は「既知である」ことの出典。
- **言い切れる強さ: 強い。** 数値と閉形式が一致している。

## 段 2 —— 統合の仕方が毎回変わったら

**問い。** 三篇は一つの作用素を繰り返す。段ごとに変わってよいはずである。

**コードが決めること。** `ρ(A₁), ρ(A₂) < 1` でも、交互に当てると発散する例があります。

```
A₁ = 0.7·[[1,1],[0,1]]     ρ = 0.7      片方だけ 40 段 → 2.6e-05
A₂ = 0.7·[[1,0],[1,1]]     ρ = 0.7      交互に  40 段 → 200.5
A₂A₁                       ρ = 1.283
```

**「各段が縮小写像なら全体も縮む」は、切り替えが入ると成り立ちません。**決めるのは
同時スペクトル半径（JSR）で、上下から挟んで判定します。共通のリアプノフ関数 `P` が
一つ見つかれば、**切り替え方を問わず**収束が確定します。

三篇の設定（巡回置換の順逆）は素直に通ります。**置換が等長だからです。**
一般の `Q` に替えた瞬間に通らなくなる、というのが上の例です。

- **独自性: 低。** JSR も共通リアプノフ関数も切り替え系の標準的な道具（Jungers 2009）。
- **合法性: 問題なし。**
- **言い切れる強さ: 場合による。** 下界が 1 を超えれば発散が確定、共通 `P` が見つかれば収束が確定。**どちらも出ないときは決まりません。**黄金比の例（`γ = 1/φ`）では JSR がちょうど 1 に挟まれて動きません。しかもこれは計算不足ではなく、**`JSR ≤ 1` の判定は決定不能である**ことが知られています（Blondel–Tsitsiklis 2000）。

## 段 3 —— 統合の仕方が偶然で決まるなら

**問い。** 毎回くじで決まるとき、「収束する」とは何か。

**コードが決めること。二つの意味があり、一致しません。**

| | 判定 | 性質 |
| --- | --- | --- |
| 二乗平均 | `ρ(E[A⊗A]) < 1` | **厳密に決まる。**線形の漸化式 |
| ほとんど確実 | リアプノフ指数 `λ < 1` | **推定。**乱数を回して測る |

`γ·[[1,1],[0,1]]` と `γ·[[1,0],[1,1]]` を等確率で引く系で、割れる窓が出ます。

```
二乗平均の境目    γ = 0.662153     （厳密）
ほとんど確実の境目 γ = 0.673019     （推定）
窓の幅            0.010866
```

窓の中（`γ = 0.667`）では、**ほとんどすべての道筋が 0 へ行くのに、平均は発散します。**
第 400 段で厳密な `E‖x‖²` は 212.3、`‖x‖` の中央値は 0.024。同じ系です。

- **独自性: 低。** 二乗平均安定とほとんど確実安定の食い違いは確率的線形系の基本事項。
- **合法性: 問題なし。**
- **言い切れる強さ: 半分。** 二乗平均の側は厳密、**リアプノフ指数の側は推定で、上下から挟んでいません。**窓の境目もその推定に依存しています。

## 段 4 —— 統合が線形でなくなったら

**問い。** 統合が線形でなければならない理由は無い。何が最初に落ちるか。

**コードが決めること。落ちるのは「唯一性」です。**

`f(x) = D tanh(βQx) + (I−D)p`、`a = 0.9` として:

| β | 不動点 | 原点の `ρ(Df)` |
| --- | --- | --- |
| 1.0 | 1 個 | 0.90 |
| 1.2 | 3 個 | 1.08 |
| 5.0 | 3 個 | 4.50 |

`β` を上げると原点は**不動点のまま残るが、引き寄せなくなり**、代わりに二点が現れます。
初期値によって行き先が変わる。**三篇の「任意の初期値から唯一の不動点へ」は、
統合という考え方から出る結論ではなく、線形だから出ていたものです。**

増えた不動点それぞれのまわりでは、段 1 の道具で局所的な縮小が示せます。
**ただしその距離は不動点ごとに違います。**一つの距離で全部は覆えません。

- **独自性: 低。** 非線形写像の多安定も局所縮小も力学系の教科書の題材。
- **合法性: 問題なし。**
- **言い切れる強さ: 弱い。** 箱の中の `‖Df‖` の最大を**標本で**取っているだけで、上界ではありません。標本を 200 → 20000 に増やすと最大値は上がります（0.006036 → 0.006048）。**上がり続けるのかどうかは標本からは分かりません。**区間演算か `Df` のリプシッツ定数が要ります。

## 段 5 —— 要素が無限個なら

**問い。** Series III は「任意の `n ≥ 2`」を示した。`n → ∞` は言えるか。

**コードが決めること。言えません。しかも壊れ方が具合の悪い形です。**

重み付き片側ずらしを `n×n` で切ると狭義下三角、つまり**冪零**になります。

| | 切り出しの値 | 無限次元の本当の値 | 一致 |
| --- | --- | --- | --- |
| `‖A‖₂` | 0.9 | 0.9 | する |
| `ρ`（輪を閉じる） | 0.9 | 0.9 | する |
| `ρ`（端で切る） | **0.0（どの `n` でも）** | 0.9 | **しない** |

`n` を上げても近づきません。精度の問題ではありません。

**そして、これはこちらの主張を弱めます。**ここまで「論文は `‖A‖₂` を使っているが
効いているのは `ρ` だ、`ρ` のほうが鋭い」と言ってきました。無限次元では
**鋭さと計算しやすさが逆転し、論文が使っていた `‖A‖` のほうが安全**になります。

- **独自性: 低。** 重み付きシフトのスペクトルも、切り出しでスペクトルが渡らないことも標準的な題材。
- **合法性: 問題なし。**
- **言い切れる強さ: 強い（ただし片側）。** 「切り出しの `ρ` が 0 である」は厳密に示せます。「本当の値が 0.9 である」は**解析的に分かっている値で、このコードが計算したものではありません。**有限のコードで無限次元の量を直接は確かめられません。

## まとめ —— どこまで行けるか

| 段 | 独自性 | コードで言い切れるか | NumPy で届くか |
| --- | --- | --- | --- |
| 1 最善のノルム | 低（測定値のみ新しい） | **言い切れる**（閉形式と一致） | 届く |
| 2 切り替え | 低 | 場合による（決定不能な場合がある） | 挟むところまで |
| 3 確率 | 低 | 半分（二乗平均は厳密、指数は推定） | 二乗平均だけ |
| 4 非線形 | 低 | **言い切れない**（標本評価） | 届かない |
| 5 無限次元 | 低 | 片側だけ | 有限の側だけ |

**独自性はどの段も低い。**これは謙遜ではなく事実です。どれも既存の分野の標準的な
道具で、教科書に載っています。**この作業で新しいのは、三篇の作用素という一つの
対象について、それらを実際に走らせて数値を出し、どこで何が落ちるかを並べたこと
だけです。**

正直に言えば、**この方向で新規性のある数学が出る見込みは低い。**出るとすれば
数学ではなく、次のどれかです。

- **再現性の道具として。** 検証スクリプト群（現在 22 + 51 + 63 = 136 項目）と、
  紙面の記述を PDF から突き合わせる仕組み（trinity-infinity 側 28 項目）は、
  それ自体が独立した成果物になりえます。JOSS のようなソフトウェア論文の形。
- **訂正の記録として。** 自分の論文の誤りを、消さずに、検査つきで残す形式。
  これは既に `ERRATA.md` が担っています。
- **教材として。** 「十分条件と必要条件の違い」「非正規行列の過渡的増幅」
  「切り替えると壊れる」を、一つの具体例で通しで見せる材料。

## ここから先 —— NumPy では届かない場所

届かないことを、届いたふりで埋めないために書いておきます。

| やりたいこと | 要るもの | なぜ NumPy で足りないか |
| --- | --- | --- |
| 段 2 の挟みを狭める | 多項式リアプノフ関数（SOS） | 半正定値計画のソルバが要る |
| 段 4 を証明にする | 区間演算、または `Df` のリプシッツ定数 | 標本では箱の中の最大を押さえられない |
| 段 3 の指数を挟む | 不変測度の評価 | 乱数の推定では上下界にならない |
| 段 5 を無限次元で言う | 作用素論の議論 | 有限の計算からは原理的に出ない |
| 段 2 の判定を一般に | **無い** | `JSR ≤ 1` の判定は決定不能 |

最後の行が壁です。**「まだやっていない」ではなく「一般にはできない」**側の問題で、
計算資源を増やしても超えられません。
